Behind the scenes

How this site was built

In the same spirit as the money page: nothing hidden. Here's the stack, and who put it together.

Built by

The Victorians Youth committee, directing the design and content — built and iterated on with Claude Code, Anthropic's AI coding assistant.

The stack

No framework, no build step — plain files that load fast and are easy to hand off.

  • Frontend
    Vanilla HTML, CSS & JavaScript

    Every page is generated from one shared set of modules and a per-year content file — no framework, no build step, no dependencies to keep updated.

  • Backend
    Google Apps Script

    One script, bound to the parish's own Google Sheet, handles donations, lucky-draw ticket sales, the staff counter, and the live donor wall.

  • Hosting
    GitHub Pages

    Free, static hosting straight from the repository — no server to maintain.

  • Payments
    Direct UPI

    Donations and tickets go straight to the parish by UPI. No payment gateway, no platform fee.
